CONTEXT: I'm building a Streamlit analytics dashboard for a class project. Treat this as one complete build: read every section below, then build the whole app in one pass before showing me anything.

DATA: The data lives in campaign_data.csv, already uploaded to this project. It has columns for platform, campaign name, date, spend (shown as Acquisition_Cost), impressions, clicks, conversions, audience, and campaign goal. The platforms are Facebook, Instagram, Pinterest, and Twitter.

DATA CLEANING: Acquisition_Cost comes in as text with a dollar sign and commas, like $1,245.00. Strip those characters and convert the column to a float before using it in any calculation. Parse the date column into a real datetime column too, not a text string, so date filtering and sorting both work correctly.

METRICS: Calculate total spend, total impressions, total clicks, and total conversions. Calculate three rates too: CTR as a percentage (total clicks divided by total impressions), CPC in dollars (total spend divided by total clicks), and ROI as a percentage ((conversions value minus spend) divided by spend). Every number shown on screen needs its unit, a dollar sign for spend and CPC, a percent sign for CTR and ROI.

LAYOUT: Build four tabs. Overview: five metric cards up top (total spend, total conversions, average CTR, average CPC, average ROI), plus a line chart showing spend and conversions over time. Platform Performance: a bar chart comparing total spend by platform, a second bar chart comparing average ROI by platform, and a summary table showing each platform's spend, clicks, conversions, and ROI side by side. Campaign Deep Dive: a searchable table of every campaign with sortable columns, plus a small conversion funnel showing total impressions, total clicks, and total conversions as three connected stages. Trends Over Time: a line chart with a dropdown so I can choose which metric to show (clicks, conversions, or ROI), grouped by week if the date range is more than a couple months.

STYLING: Keep the layout clean and readable, real section headers, a little spacing between elements, and numbers that line up instead of wrapping awkwardly.

TECH NOTES: Build a sidebar with four filters that apply to every tab at once: a date range picker, a platform multi-select, an audience multi-select, and a campaign goal multi-select. Compute the filtered dataframe once, right after the filters are set, and have every tab read from that same filtered dataframe. That is what keeps every chart and table in sync when a filter changes. Calculate every number from the actual data, never hardcode an example value as a placeholder. If a filter combination returns zero campaigns, show a clear message like "No data for selected filters" instead of a blank or broken page.
